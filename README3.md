# Лабораторная работа № 3*. Дерево решений CART

В текущей реализации проекта используются звёздочные треки лабораторных:
решающий пень для ЛР2 и CART для ЛР3. Полные условия: [lab_2_star.md](lab_2_star.md)
и [lab_3_star.md](lab_3_star.md).

CART развивает поиск разбиения пня, используя общий `SplitFinder`. Оба алгоритма
поддерживают регрессию и классификацию. Проект сохраняет общие `IModel`,
`IRegressor`, `IClassifier`, `Matrix` и `MatrixSlice`.

Сборка и тесты:

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
```

**С агентом:** можно поручать написание тестов и тестовых данных. Самостоятельные
решения — интерфейсы, срезы матрицы, пень и CART — студент должен понимать и
уметь объяснить.
