## Лабораторная работа №4 — Random Forest

Цель лабораторной работы — изучить композицию моделей на деревьях решений и
реализовать случайный лес для классификации и регрессии. В проекте реализация
находится в `src/random_forest.hpp` и `src/random_forest.cpp`. Random Forest — композиционная модель для
классификации и регрессии: она обучает несколько деревьев CART и объединяет
их ответы. В отличие от одного CART, лес строит каждое дерево на собственной
bootstrap-выборке и при поиске разбиения случайно ограничивает набор
рассматриваемых признаков в каждом узле. Это вносит разнообразие в деревья;
результат леса агрегирует их предсказания.

### Модели и параметры

Для регрессии используется `RandomForestRegressor`, для классификации —
`RandomForestClassifier`. Обе модели реализуют общие интерфейсы `IRegressor` и
`IClassifier`. Параметры передаются через `RandomForestParams` в конструктор
модели. Значения по умолчанию структуры:

| Параметр | Значение по умолчанию | Поведение |
|---|---:|---|
| `n_estimators` | `100` | Число деревьев; должно быть больше нуля. |
| `bootstrap` | `true` | Формировать bootstrap-выборку с возвращением для каждого дерева. При `false` каждое дерево получает всю обучающую выборку. |
| `max_samples` | не задан (`nullopt`) | Размер bootstrap-выборки; по умолчанию равен числу объектов исходной выборки. Допустим только при `bootstrap=true`, больше нуля и не больше исходной выборки. |
| `max_features` | не задан (`nullopt`) | Автоматический режим: `Sqrt` для классификации и `All` для регрессии. Поддерживаются `All`, `Sqrt` и `Count`; `Count` задаёт число признаков от 1 до числа признаков матрицы. |
| `max_depth` | не задан (`nullopt`) | Максимальная глубина CART; отсутствие значения снимает это ограничение. Значение больше 64 отклоняется. `0` оставляет корень листом. |
| `min_samples_split` | `2` | Минимальное число объектов узла для попытки разбиения; минимум 2. |
| `min_samples_leaf` | `1` | Минимальное число объектов в листе; минимум 1. |
| `random_state` | `0` | Начальное состояние, используемое для построения seed деревьев. |
| `n_jobs` | `1` | Запрошенное число рабочих потоков; минимум 1. Фактическое число ограничивается числом задач. |

`max_features` использует `FeatureSearchParams`: `FeatureMode::All`,
`FeatureMode::Sqrt` или `FeatureMode::Count` и поле `count` для режима
`Count`. При `Sqrt` CART берёт целую часть квадратного корня числа признаков,
но не меньше одного. Для режима `Count` значение также проверяется
относительно числа признаков при обучении.

В CLI доступны выбор `--model random_forest`, задача `--task`, целевой столбец,
`--max-depth`, `--min-samples-split`, `--min-samples-leaf`, `--n-estimators` и
`--n-jobs`. Приложение задаёт `random_state=42` и использует автоматический
`max_features`; `bootstrap` включён, а `max_samples` не задан. Другие варианты
этих параметров задаются через C++ API, не через командную строку.

Пример запуска приложения с уже существующим CLI и входным CSV:

```powershell
.\build\lab1.exe --input ".\bank-additional\bank-additional\bank-additional.csv" --model random_forest --task classification --target y --max-depth 5 --min-samples-split 2 --min-samples-leaf 1 --n-estimators 100 --n-jobs 4
```

### Устройство и обучение

Лес повторно использует CART: `RandomForestRegressor` хранит
`vector<unique_ptr<CartRegressor>>`, а `RandomForestClassifier` —
`vector<unique_ptr<CartClassifier>>`. Каждый объект CART владеет корневым узлом,
а узлы владеют потомками через `unique_ptr`. Лес вызывает у CART
`fit_with_counts()`, передавая кратности объектов, поэтому повторяющиеся
bootstrap-выборки учитываются как веса, без копирования строк обучающей матрицы.
При отключённом bootstrap каждому объекту назначается кратность 1.

Для каждого дерева формируется независимый seed из `random_state` и индекса
дерева; этим seed инициализируется генератор для bootstrap-выборки и передаётся
в CART для случайного выбора признаков. Задачи обучения записывают дерево в
ячейку своего индекса в заранее выделенном векторе. После окончания всех задач
вектор становится состоянием модели. Поэтому порядок завершения потоков не
меняет порядок деревьев и их последующей агрегации.

Регрессор проходит деревья в порядке индексов и усредняет их значения для
каждой строки, накапливая сумму в `long double`. Классификатор получает из
деревьев вероятности классов и усредняет вероятности по деревьям. Список
`classes()` лес копирует из первого дерева; CART возвращает отсортированные
метки классов, встреченные при обучении этого дерева. `predict()` выбирает
класс с наибольшей усреднённой вероятностью; при равенстве остаётся первый
столбец результата. `predict_proba()` возвращает матрицу «строки объектов ×
столбцы классов».

При обучении классификатора каждое дерево получает полный целевой вектор и
свои bootstrap-кратности. `CartClassifier::fit_with_counts()` формирует общий
отсортированный список меток по всему целевому вектору, в том числе для классов,
которые не попали в bootstrap-выборку конкретного дерева. Поэтому все деревья
используют одинаковый порядок столбцов вероятностей. Если класс отсутствует в
bootstrap-выборке дерева, его счётчик и вероятность для этого дерева равны нулю.
Лес может корректно усреднять вероятности по индексам столбцов.

Для фиксированных входных данных и `random_state` каждый индекс дерева всегда
получает тот же seed, независимо от того, какой поток выполнит задачу. При
агрегации деревья обходятся в порядке индексов в каждом пакете строк; поэтому
смена `n_jobs` не меняет порядок сложения для соответствующей строки. Разбиение
строк по рабочим задачам также сохраняет исходный порядок результатов.

### Параллельное выполнение

Общий `parallelFor` выполняет задачи обучения деревьев, а при предсказании
распараллеливает пакеты строк. Он создаёт не более `min(n_jobs, число задач)`
рабочих `std::jthread`. Потоки получают номера задач через атомарный счётчик;
при предсказании диапазоны строк детерминированно делятся по индексам. Объекты
`jthread` ожидают завершения в деструкторах.

Исключение из рабочей задачи перехватывается внутри потока, первое исключение
сохраняется как `exception_ptr`, новые задачи останавливаются, потоки
дожидаются завершения, после чего исключение повторно выбрасывается в
вызывающем потоке. При `n_jobs=1` задачи выполняются последовательно без
создания рабочих потоков.

### Проверки и ограничения

- Обучение отклоняет пустую выборку, матрицу без признаков и несовпадение числа
  строк и целевых значений. CART также отклоняет нечисловые или бесконечные
  значения признаков и целевых значений.
- Параметры проверяются при создании модели и обучении: число деревьев и
  `n_jobs` должны быть положительными, `min_samples_split >= 2`,
  `min_samples_leaf >= 1`; `max_samples` должен быть положительным и не больше
  размера обучающей выборки. Указать `max_samples` при `bootstrap=false`
  нельзя.
- Для `max_features=Count` количество должно быть положительным и не больше
  числа признаков. Максимальная глубина ограничена значением 64.
- До успешного обучения `predict()`, `predict_proba()`, `classes()` для
  классификатора и `tree_summaries()` бросают `ModelUsageError`. После обучения
  число признаков при предсказании должно совпадать с обучающей матрицей;
  признаки с некорректными значениями отклоняются CART.
- Пустая матрица строк для предсказания допустима и возвращает пустой результат.
  Для регрессии дополнительно проверяется конечность итоговых предсказаний.
- Повторное обучение сначала собирает новый набор деревьев и заменяет
  состояние после успешного выполнения; исключение рабочего потока передаётся
  вызывающему коду.

## Benchmark

Для оценки производительности Random Forest проведено сравнение
последовательного и параллельного выполнения с использованием `n_jobs = 1` и
`n_jobs = 4`.

### Конфигурация эксперимента

| Параметр | Значение |
|---|---|
| Тип сборки | Release |
| Обучающая выборка | 6000 объектов |
| Тестовая выборка | 1500 объектов |
| Количество признаков | 16 |
| Количество деревьев | 50 |
| Максимальная глубина | 12 |
| `bootstrap` | `true` |
| `max_samples` | не задан; размер bootstrap-выборки равен 6000 |
| `max_features` (регрессия) | `All` (значение по умолчанию) |
| `max_features` (классификация) | `Sqrt` |
| `min_samples_split` | 2 (значение по умолчанию) |
| `min_samples_leaf` | 1 (значение по умолчанию) |
| `random_state` | 42 |
| Количество повторов | 5 |
| Число потоков | 1 и 4 |

Данные генерируются синтетически с фиксированным seed `20261123`. Значения
признаков равномерно распределены в диапазоне от −1 до 1. Для регрессии
целевая переменная формируется как взвешенная сумма первых шести признаков.
Для классификации используется бинарная метка, определяемая знаком этой суммы.

Для классификации используется `max_features = Sqrt`. Для регрессии используется
значение `max_features` по умолчанию.

Время генерации данных не включается в измерения. Отдельно измеряются обучение
модели (`fit`), пакетное предсказание (`predict`) и вычисление вероятностей
классов (`predict_proba`).

Каждый эксперимент выполняется пять раз. В таблицах приведена медиана времени
выполнения.

### Выводы

Параллельное выполнение Random Forest показало заметное ускорение на четырёх
потоках. Наибольшее ускорение в этом запуске получено при обучении
классификационной модели — 3.95 раза. Обучение регрессионной модели ускорилось
в 3.84 раза.

Полученные результаты демонстрируют эффективность распараллеливания обучения и
предсказания. При этом ускорение зависит от типа задачи, объёма данных и
количества потоков.

Эксперимент проводился на синтетических данных. Контрольный запуск выполнен
после конфигурации и полной сборки в отдельном чистом каталоге
`build-benchmark-clean`; результаты характеризуют производительность реализации
в указанной конфигурации оборудования и программного окружения.
