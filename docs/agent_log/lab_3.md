## Эпизод 2 — аудит трека CART со звёздочкой

- **Запрос:** сопоставить реализацию с полным `lab_3_star.md`, добавить
  недостающие автоматические проверки, вывести статистику дерева в приложении,
  обновить README и журнал; не переписывать алгоритм.
- **Подтверждённые исходные пробелы:** отсутствовала остановка на одинаковых
  откликах; ничьи зависели от порядка списка признаков; `midpoint` мог округлиться
  к правой границе; CLI не показывал статистику дерева. Проверки не покрывали
  tie-breaking, adjacent doubles, feature subset у `SplitFinder`, классификацию
  против пня, refit/empty prediction и parity layout.
- **Изменения:** `CartRegressor` и `CartClassifier` теперь останавливаются для
  одинаковых откликов. `SplitFinder` выбирает меньший индекс признака, затем
  меньший порог при равном score; защищает порог от округления к правой границе;
  проверка минимального размера листа не переполняется; неконечный score и
  нечисловое предсказание регрессионного листа приводят к исключению. Глубина выше 64
  отклоняется как защита рекурсивной демонстрационной реализации. Добавлены
  `CartTreeSummary`/`summary()`; приложение выводит число узлов, листьев,
  фактическую глубину и до пяти разбиений. Индексные `Matrix`/`MatrixSlice`
  операторы сделаны unchecked/noexcept, добавлен checked `Matrix::at(row,col)`;
  `MatrixSlice` получил default-state и проверяемый `at()` по условию.
- **Тесты:** добавлена цель CTest `cart_audit_tests` с проверками равных оценок,
  соседних представимых значений, списка разрешённых признаков, одинаковых
  откликов, классификационного совпадения с пнём, порядка классов и вероятностей,
  повторного обучения, пустых прогнозов, параметров, сводки дерева и обоих
  layout. Также проверяются один объект, минимум объектов в листе, ошибки
  контрактов fit/predict, глубина 2 против глубины 1 и default/checked
  `MatrixSlice`. Существующая проверка выхода за границу матрицы сохранена и
  переведена с unchecked `operator()` на `at(row, column)`.
- **Сборка и предупреждения:** `make -C build -j2` после правок успешно собрал
  приложение и шесть тестовых целей. Используемые флаги из `flags.make`:
  `-Wall -Wextra -Wpedantic`; предупреждений при сборке изменённых файлов не было.
  Первая компиляция audit test обнаружила неоднозначные списки инициализации
  `Matrix` и обращение к элементу временной матрицы (которое правильно запрещено
  ref-квалификатором); тест исправлен явным типом вектора и именованной матрицей.
- **CMake и CTest:** через CMake 3.31, указанный в build files,
  `cmake --build build` завершился успешно; прямой `ctest --test-dir build
  --output-on-failure` прошёл: 6/6. CTest включает новую `cart_audit_tests`.
- **Проверка приложения:** запуски CART classification и regression на
  локальном `bank-additional.csv` с `max-depth=2` показали по 7 узлов, 4 листа,
  фактическую глубину 2 и по три описания split. Это smoke-runs; регрессионные
  метрики (MAE 6.708, RMSE 8.347) не подменяют таблицы ранее предоставленных
  экспериментов. Классификационный вывод показывает обратные метки `no/yes`.
- **ASan/UBSan:** обычная CMake-конфигурация сообщает, что sanitizer отключён
  для Windows. Отдельная Debug-конфигурация GCC с явными
  `-fsanitize=address,undefined` завершилась ошибкой линковки: отсутствуют
  `-lasan` и `-lubsan`. Запуск с sanitizer instrumentation не подтверждён.
- **Оставшееся ограничение:** выбранный верхний предел глубины 64 — решение
  реализации; условие требует разумно ограничить рекурсивную демонстрацию, но
  точное числовое значение не задаёт.
